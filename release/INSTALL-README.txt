KEYMON Installer

Setup file location in this repo:
release/KEYMON-Setup.exe

Google Drive upload copy:
C:\Users\user\Downloads\KEYMON-GoogleDrive-Upload\KEYMON-Setup.exe

How to install:
1. Double-click KEYMON-Setup.exe.
2. If Windows SmartScreen appears, click "More info", then "Run anyway".
3. KEYMON installs to your user app folder.
4. A KEYMON shortcut appears on your Desktop and in the Start Menu.
5. Open KEYMON from the Desktop shortcut.

Note:
Windows may show a warning because this installer is not code-signed yet. This is common for new apps shared directly through Google Drive.
